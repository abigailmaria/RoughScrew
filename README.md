# RoughScrew

RoughScrew enables real-time, event-driven processing on distributed architectures with and load-balancing via a scalable orchestrator and scheduler framework.

RoughScrew is aimed at developers who need a straightforward, dependable solution.

**Highlights**

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughScrew.git`
2. `cd RoughScrew`
3. Install in editable mode: `pip install -e .`

## Configuration

RoughScrew is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
